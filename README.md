# 🧾 FacturApp – Prototipo UI en HTML y Bootstrap

## 📌 Descripción

Este repositorio contiene un **prototipo visual de interfaz de usuario** para una aplicación de facturación llamada **FacturApp**, desarrollado utilizando **HTML5 y Bootstrap 4**.

El objetivo principal del proyecto es mostrar una estructura básica, organizada y visualmente atractiva de un sistema de inventario/productos, que pueda servir como base para una futura implementación con backend y base de datos.

> ⚠️ Nota: Este proyecto es únicamente un prototipo visual (frontend).

---

## 🛠️ Tecnologías Utilizadas

- HTML5  
- Bootstrap 4  
- CSS 
- JavaScript
